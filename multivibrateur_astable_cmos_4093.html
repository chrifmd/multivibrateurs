Simulation pédagogique — astable à porte CD4093 CMOS (VT+ = 0,75 VDD, VT- = 0,50 VDD).

Aperçu Théorique

Le circuit intégré CD4093 contient quatre portes NAND à Trigger de Schmitt. En reliant ses deux entrées, il agit comme un inverseur avec hystérésis défini par deux seuils de basculement :

  • Seuil haut (VT+) : ~ 0,75 · VDD
  • Seuil bas (VT-) : ~ 0,50 · VDD

Équations Théoriques Simplifiées

En remplaçant les seuils simplifiés dans les équations de charge et décharge :

TH = R · C · ln( (VDD - VT-) / (VDD - VT+) ) = R · C · ln(0,5 / 0,25) = R · C · ln(2) ≈ 0,69 · R · C
TB = R · C · ln( VT+ / VT- ) = R · C · ln(0,75 / 0,50) = R · C · ln(1,5) ≈ 0,41 · R · C

Période globale et fréquence :

T = TH + TB ≈ 1,1 · R · C
N = 1 / T ≈ 1 / (1,1 · R · C)
