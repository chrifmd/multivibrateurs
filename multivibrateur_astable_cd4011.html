Aperçu Théorique

Le circuit intégré CD4011 comprend 4 portes NAND CMOS avec un seuil unique de basculement VS = 0,5 · VDD.

Comportement du Condensateur C

  • Tension uC(t) : Strictement continue, oscille entre -0,5 · VDD et +0,5 · VDD.
  • Tension uE2(t) : Impulsions comprises entre -0,5 · VDD et 1,5 · VDD.

Équations

T1 = T2 = R · C · ln(3) ≈ 1,1 · R · C
T = 2 · R · C · ln(3) ≈ 2,2 · R · C
N = 1 / T ≈ 1 / (2,2 · R · C)
le rapport cyclique est fixe: δ= TH / T =0,5 = 50 %
